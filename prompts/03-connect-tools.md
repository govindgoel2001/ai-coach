# Tool connection prompt

I want this coach to use my real data instead of generic assumptions.

Inspect the available MCPs, APIs, files, and local tools. Build a TOOL_MAP.md with:

- data source
- what fields it provides
- freshness
- read/write permissions
- privacy sensitivity
- which coaching decisions it improves

Examples:
- Huberman-style health coach -> sleep, HRV, resting HR, activity, calendar
- Buffett-style investing coach -> holdings, allocation, cash, returns, filings/watchlist
- Goggins-style discipline coach -> workouts, streaks, tasks, calendar
- business coach -> CRM, revenue, offers, ad analytics, content analytics

Default to read-only. Ask before any external side effect.
